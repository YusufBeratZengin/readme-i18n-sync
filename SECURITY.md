# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability in `readme-i18n-sync`, please do not report it via a public GitHub issue.

Please report vulnerabilities privately via GitHub Security Advisories at:
https://github.com/YusufBeratZengin/readme-i18n-sync/security/advisories

Alternatively, contact the maintainer directly. You will receive a response within 48 hours acknowledging receipt of your report.
